# Backup Scripts

Automated backup, cloud sync, and recovery tools for the CRM platform.

## Quick start

```bash
# 1. Run the interactive setup (creates dirs, encryption, cloud, scheduling)
sudo ./setup.sh

# 2. Test a database backup
./backup-database.sh --logical --sync

# 3. Test a file backup
./backup-files.sh

# 4. Verify everything
./verify-backup.sh

# 5. View logs
tail -f /var/log/crm-backup.log
```

## Scripts

| Script | Purpose | Key flags |
|---|---|---|
| `setup.sh` | Interactive installer — bootstraps everything | Run once with `sudo` |
| `backup-database.sh` | Postgres backup (physical or logical) with encryption | `--logical`, `--sync` |
| `backup-files.sh` | Back up user uploads, app config, and git repo | `--config-only`, `--uploads-only` |
| `sync-to-cloud.sh` | Sync backups to Google Drive, S3, OneDrive, or personal drive | `--source=<file>`, `--destination=<name>` |
| `restore-database.sh` | Restore DB from local, cloud, or personal drive | `--backup=<path>`, `--from-cloud=<src>`, `--target-time=<ts>` |
| `verify-backup.sh` | Validate freshness, integrity, restore, and disk space | `--full`, `--post-restore` |
| `archive-wal.sh` | Archive WAL segments (called by PostgreSQL) | `%p %f` |
| `cleanup-old-backups.sh` | Remove old backups per retention policy | `--dry-run` |
| `watch-config.sh` | Watch config dirs, auto-backup on change | Runs as systemd service |
| `backup.conf` | Shared configuration for all scripts | Generated by `setup.sh` |

## Supported destinations

- **Google Drive** — via rclone (`gdrive`)
- **AWS S3** — via rclone (`s3`)
- **OneDrive** — via rclone (`onedrive`)
- **Personal / USB drive** — direct rsync to mounted path
- **Any rclone remote** — 40+ cloud providers supported

## Automated schedule

Installed by `setup.sh` via cron or systemd timers:

| Task | Frequency | Script |
|---|---|---|
| Physical DB backup | Daily 2 AM | `backup-database.sh --sync` |
| Logical DB dump | Every 6 hours | `backup-database.sh --logical` |
| Upload sync | Hourly | `backup-files.sh --uploads-only` |
| Full file backup | Daily 3 AM | `backup-files.sh` |
| Cloud sync | Every 4 hours | `sync-to-cloud.sh` |
| Old backup cleanup | Weekly Sunday | `cleanup-old-backups.sh` |
| Backup verification | Weekly Saturday | `verify-backup.sh` |
| Config change watch | Continuous | `watch-config.sh` (systemd) |

## Recovery

```bash
# From local backup
./restore-database.sh --backup=/backups/postgres/logical/crm_20260411.dump

# From Google Drive
./restore-database.sh --from-cloud=gdrive

# From personal drive
./restore-database.sh --from-cloud=personal

# From AWS S3
./restore-database.sh --from-cloud=s3

# Point-in-time recovery
./restore-database.sh --backup=/backups/postgres/base/crm_base_20260411.tar.gz \
  --target-time="2026-04-11 14:30:00 UTC"
```

## Cleanup

```bash
# Preview what would be deleted
./cleanup-old-backups.sh --dry-run

# Actually clean up
./cleanup-old-backups.sh
```
